# SchemaTeX VSCode Extension

SchemaTeX is a Visual Studio Code extension for SystemVerilog hardware design that generates synchronized diagrams of your code.

## Features

- Generate diagrams from SystemVerilog files
- AI-powered diagram simplification using Claude API
- Export diagrams to multiple formats

## Structure

```
extension/
├── src/
│   ├── extension.ts              # Main extension entry point
│   ├── extension.test.ts         # Extension tests

├── package.json                  # Dependencies and scripts

```

## Commands

- `SchemaTeX: Show Diagram` (Ctrl+Shift+D) — Display diagram for current Verilog file
- `SchemaTeX: Simplify with AI` — Simplify diagram using Claude
- `SchemaTeX: Export Diagram` — Export diagram to various formats

## Setup

### Prerequisites

- Node.js 16+
- npm 7+

### Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Compile TypeScript:
   ```bash
   npm run compile
   ```

3. Watch for changes:
   ```bash
   npm run watch
   ```

4. Run tests:
   ```bash
   npm test
   ```

## VS Code Secrets API

The extension uses the VS Code Secrets API to securely store the Claude API key. The key is retrieved from `context.secrets` and prompted for on first use.

See `src/claude-integration.ts` for implementation.

## Architecture

### Extension Flow

1. **Extension Activation** (`extension.ts`)
   - Initialize Claude integration
   - Register commands
   - Create webview provider

2. **Parser Bridge** (`parser-bridge.ts`)
   - Spawns parser CLI subprocess
   - Handles JSON AST output
   - TODO: Integrate with actual parser (#7)

3. **Webview Provider** (`webview-provider.ts`)
   - Manages webview panel creation
   - Loads React app
   - Communicates with extension via messages

4. **Claude Integration** (`claude-integration.ts`)
   - Stores API key securely in VS Code Secrets
   - Provides API key retrieval
   - TODO: Implement simplification API (#18)

### Webview

- Built with React + TypeScript
- Uses VS Code theme colors via CSS variables
- Renders diagrams using ELK layout (planned) and custom SVG
