# Issue Tracker: GitHub Issues

Issues for this project live in GitHub Issues.

## Creating issues

Use `gh issue create` to open a new issue from the command line, or use the GitHub web interface.

## PRs as request surface

By default, pull requests do NOT feed into the triage queue. If you want external PRs to be triaged alongside issues, set `prs_as_requests: true` in this file.

Currently: `prs_as_requests: false`
