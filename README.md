# SchemaTeX Web App

Interactive tool to visualize SystemVerilog RTL code as block diagrams.

## Quick Start

```bash
npm install --prefix prototype-tester
npm start --prefix prototype-tester
```

Open http://localhost:3000 in your browser.

## Usage

Paste SystemVerilog code, click Parse, see the diagram.
